### E-Commerce Product API

A RESTful e-commerce backend built with Django REST Framework and PostgreSQL.

**Tech:** Python · Django · DRF · PostgreSQL · Token Authentication · Swagger

**Features:**

* User registration and token-based authentication
* Protected API endpoints
* Product and category CRUD operations
* Automatic product ownership
* Product search and filtering
* Price and stock filtering
* Pagination
* Swagger UI, ReDoc, and OpenAPI documentation
* Production deployment with PythonAnywhere
